8. 已确认的物理组织

Data SRAM：512 × 128 bit
[127:96] = Way 3
[95:64] = Way 2
[63:32] = Way 1
[31:0] = Way 0

Metadata SRAM：64 × 100 bit
[99:92] = 8-bit True LRU Replacement
[91:69] = Way 3 Metadata
[68:46] = Way 2 Metadata
[45:23] = Way 1 Metadata
[22:0] = Way 0 Metadata

每Way Metadata：23 bit
[22] = Valid
[21] = Dirty
[20:0] = Tag

SRAM有效条件
Read：ME=1, WE=0
Write：ME=1, WE=1, WEM目标bit=1
